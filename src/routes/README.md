# Routes

This project uses TanStack Router with **file-based routing**. Every `.tsx` file in this directory defines a route.

| File | URL |
| --- | --- |
| `index.tsx` | `/` |
| `about.tsx` | `/about` |
| `__root.tsx` | app shell — wraps every page via `<Outlet />` |

`routeTree.gen.ts` is auto-generated by the TanStack Router Vite plugin. Don't edit it by hand.
